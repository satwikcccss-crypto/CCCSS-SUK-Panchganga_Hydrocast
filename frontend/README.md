## Getting Started

### Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

3. Build production bundle:
   ```bash
   npm run build
   npm run start
   ```
