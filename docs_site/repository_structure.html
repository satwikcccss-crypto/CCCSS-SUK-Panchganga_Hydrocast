Core Engineering Modules

  • /src/hydrology: Contains the SCS-CN infiltration model, unit hydrograph generators, and runoff computational cores.
  • /src/hydraulics: 2D Divided Channel Method (DCM) and rating curve translation modules for Shivaji Bridge and Rajaram Weir.
  • /src/ml_calibration: Physics-informed adaptive recalibration engine utilizing Scipy L-BFGS-B optimization.
  • /src/alerts: Telegram Bot API integration and automated warning dissemination systems.
  • /database: SQLite state tracking, historical stage observations, and caching systems.
  • /gis: Spatial GeoJSON delineations of the 9 subbasins, 14 river reaches, and 20 rain gauge stations.
  • /docs: Raw technical engineering manuals in Markdown format.

The code is fully modular, adhering strictly to USACE HEC-HMS 4.13 mathematical standards for hydrologic transformations.
