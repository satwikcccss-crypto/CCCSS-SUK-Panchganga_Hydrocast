## 1. Overview & Architecture

The **HydroCast Public API** provides unauthenticated, open-access, machine-readable scientific intelligence for the Panchganga River Basin in Kolhapur, Maharashtra. It serves researchers, GIS analysts, students, agricultural coordinators, and administrative technical cells.

* **Base URL (Localhost):** `http://localhost:8000`
* **Production Domain:** `http://hydrocast.unishivaji.ac.in` *(or university-assigned host)*
* **Interactive OpenAPI (Swagger UI):** `http://localhost:8000/docs`
* **ReDoc Documentation:** `http://localhost:8000/redoc`
* **Format:** UTF-8 JSON (`application/json`)
* **Authentication:** **None Required** (Public Endpoints are open)
* **Default Rate Limit:** 60 requests / minute per client IP (HTTP 429 on quota exhaustion)
* **CORS Policy:** Open (`Access-Control-Allow-Origin: *`)

> [!NOTE]
> **Statutory Research Disclaimer:**  
> All data provided via this API is generated by academic hydrological and hydrodynamic simulation models (SCS-CN + Muskingum-Cunge diffusion routing). This digital twin is for academic, scientific, and situational awareness purposes. For statutory flood alerts, warnings, and civil defense orders, consult the District Disaster Management Authority (DDMA) and competent government authorities.

## 2. API Endpoints Catalog

| Method | Endpoint | Description | Cache TTL |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/SUK_hydrocast_v1` | **Primary Open Access Feed** (Full basin summary, bridge stages, 90h hydrograph, rainfall) | 60 sec |
| `GET` | `/api/v1/dashboard` | Compact dashboard telemetry for frontend cards | 30 sec |
| `GET` | `/api/v1/runoff/summary` | Basin-wide peak discharge, volume (MCM), and critical bridge levels | 30 sec |
| `GET` | `/api/v1/runoff/stage/{site_id}` | 90-hour hourly water level series for specific bridge (`SHIVAJI_BRIDGE`, `RAJARAM_BRIDGE`) | 60 sec |
| `GET` | `/api/v1/alerts/bulletin` | Official academic flood simulation bulletin (administrative format) | 30 sec |
| `GET` | `/api/v1/export` | 90-hour hydrograph forecast in CSV format | Realtime |
| `GET` | `/api/v1/history` | Historical simulation cycles and verification ledgers | 60 sec |
| `GET` | `/api/v1/health` | Server health check and database connection pool verification | 5 sec |

### 3.2 Specific Bridge 90-Hour Stage Series: `GET /api/v1/runoff/stage/{site_id}`

Retrieve the full 90-hour continuous forward hydrograph curve for a specific bridge site.

#### Parameters:
* `site_id` (Path, required): `SHIVAJI_BRIDGE` or `RAJARAM_BRIDGE`

#### Example Request:
```bash
curl -X GET "http://localhost:8000/api/v1/runoff/stage/SHIVAJI_BRIDGE"
```

#### Response:
```json
{
  "site_id": "SHIVAJI_BRIDGE",
  "site_name": "Chhatrapati Shivaji Maharaj Bridge",
  "forecast_run_id": "CYC_20261110_0600",
  "stages": [
    {
      "lead_hours": 1,
      "stage_m": 531.54,
      "discharge_m3s": 9.10,
      "alert_level": "NORMAL",
      "timestamp": "2026-11-10T07:00:00Z"
    }
  ]
}
```

### 3.3 90-Hour Hydrograph CSV Download: `GET /api/v1/export`

Returns a downloadable RFC-4180 compliant CSV file suitable for Excel, Pandas, or QGIS importing.

#### Example Request:
```bash
curl -X GET "http://localhost:8000/api/v1/export" -o panchganga_90h_forecast.csv
```

#### CSV Format:
```csv
cycle_id,lead_hour,timestamp,shivaji_stage_m,shivaji_q_m3s,rajaram_stage_m,rajaram_q_m3s
CYC_20261110_0600,1,2026-11-10T07:00:00Z,531.54,9.10,532.19,9.10
CYC_20261110_0600,2,2026-11-10T08:00:00Z,531.54,9.10,532.19,9.10
```

## 4. Code Integration Examples

### Python (3.10+) Example:
```python
import requests
import json

API_URL = "http://localhost:8000/api/SUK_hydrocast_v1"

try:
    response = requests.get(API_URL, timeout=10)
    response.raise_for_status()
    data = response.json()
    
    summary = data.get("summary", {})
    bridges = data.get("bridges", {})
    
    print(f"Cycle ID      : {data.get('cycle_id')}")
    print(f"Peak Outflow  : {summary.get('peak_discharge_m3s')} m³/s")
    print(f"Shivaji Stage : {bridges.get('shivaji', {}).get('current_stage_m')} m MSL")
    print(f"Rajaram Stage : {bridges.get('rajaram', {}).get('current_stage_m')} m MSL")
    print(f"Alert Status  : {summary.get('current_overall_status')}")

except requests.exceptions.RequestException as e:
    print(f"Failed to fetch HydroCast API: {e}")
```

### JavaScript / Node.js (Fetch) Example:
```javascript
const API_URL = "http://localhost:8000/api/SUK_hydrocast_v1";

async function fetchHydrocastFeed() {
  try {
    const res = await fetch(API_URL);
    const data = await res.json();
    console.log("HydroCast Peak Outflow:", data.summary.peak_discharge_m3s, "m³/s");
    console.log("Shivaji Bridge Water Level:", data.bridges.shivaji.current_stage_m, "m MSL");
  } catch (err) {
    console.error("Error connecting to HydroCast API:", err);
  }
}

fetchHydrocastFeed();
```
