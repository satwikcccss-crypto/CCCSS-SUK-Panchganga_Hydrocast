DATABASE SCHEMA SPECS

DEDICATED TABLESPACE VOLUME 3512 GB NVMe
Windows server path: E:\pgtablespace\hydrocast.
Postgres tablespace created by windows/storage_setup.sql. Retains complete 90-hour historical forecast runs with 5-10x ZSTD compression on chunks older than 7 days.
TIMESCALEDB HYPERTABLE CHUNKS 7-DAY PARTITIONING
Tables partitioned by timestamp with 7-day chunk intervals:
• hydrograph_results (360 rows per cycle)
• bridge_stage_forecast (360 rows per cycle)
• observed_rainfall_qc (480 rows per cycle)
Sub-millisecond index scans on recent operational runs.
POSTGIS 3.4 SPATIAL EXTENSIONS EPSG:4326 & 32643
Station coordinates and catchment subbasin boundaries are stored with GEOMETRY(Point, 4326) and indexed via GiST(geom). Enables nearest-neighbor spatial queries for ungauged subbasin failovers.
FOREIGN KEY AUDIT INTEGRITY ACID COMPLIANT
All child forecast and hydrograph rows are strictly bound to run_id in simulation_runs via FOREIGN KEY ... ON DELETE CASCADE, preventing orphaned time-series data.
